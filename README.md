# CarBrowser

- Sayfa yenileme
- Sekme açma ve kapatma
- JavaScript desteği
- WebKit video oynatma desteği
- YouTube ve canlı yayın siteleriyle uyumluluk hedefi

## Teknoloji

- Swift
- SwiftUI
- WKWebView

## Gereksinimler

- iOS 16 veya üzeri
- Xcode
- Apple Developer hesabı

## Not

Bu proje başlangıç prototipidir.
CarPlay desteği henüz bulunmamaktadır.
